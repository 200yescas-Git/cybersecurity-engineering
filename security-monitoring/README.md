# Security Monitoring

## Overview

Security Monitoring es un dominio enfocado en la supervisión continua de eventos de seguridad, el análisis de registros, la detección de amenazas y la identificación temprana de actividades anómalas dentro de infraestructuras y sistemas empresariales.

Este dominio reúne documentación técnica, laboratorios, rutas de aprendizaje y recursos orientados al desarrollo de competencias relacionadas con la monitorización de seguridad y las operaciones de un Security Operations Center (SOC).

---

## Purpose

El propósito de este dominio es desarrollar competencias relacionadas con:

- Security Monitoring Fundamentals.
- Log Analysis.
- Event Correlation.
- Threat Detection.
- Security Visibility.
- Security Operations.
