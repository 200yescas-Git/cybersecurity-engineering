# Cisco Cybersecurity Analyst

## Overview

Esta ruta de aprendizaje está basada en el programa **Cisco Cybersecurity Analyst**, orientado al desarrollo de competencias relacionadas con el monitoreo de seguridad, análisis de eventos, operaciones de un Security Operations Center (SOC) y detección de amenazas en entornos empresariales.

Su propósito es proporcionar una base sólida sobre procesos, herramientas y buenas prácticas utilizadas por analistas de ciberseguridad dentro de centros de operaciones de seguridad.

---

## Objective

El objetivo de esta ruta de aprendizaje es desarrollar competencias relacionadas con:

- Security Monitoring.
- Security Operations Center (SOC).
- Log Analysis.
- Event Correlation.
- Threat Detection.
- Incident Analysis.
